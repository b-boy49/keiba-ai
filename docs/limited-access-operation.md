# 限定公開・発表会運用

## 構成

サイト本体と読み取りAPIは `middleware.ts` で保護する。未認証のページ要求は `/access` へ戻し、未認証のAPI要求は `401 AUTH_REQUIRED` を返す。アカウント登録・個人情報の保存は行わない。

`POST /api/auth/login` はサーバー側で共有パスワードを定数時間比較し、HMAC-SHA-256署名・乱数・有効期限（12時間）付きのCookieを発行する。Cookieは `HttpOnly`、`SameSite=Strict`、本番では `Secure` であり、ブラウザJavaScriptから読めない。パスワード、セッション秘密鍵、学習・承認・取込コマンドはブラウザへ送らない。

## 環境変数

`.env.example` をコピーしてホスティングサービスの**サーバー環境変数**にも同じ値を設定する。`.env.local` はコミットしない。

```text
KEIBA_ACCESS_PASSWORD=<共有する長いパスワード>
KEIBA_SESSION_SECRET=<32文字以上のランダムな秘密文字列>
```

発表会の終了後は両方を変更し、以前のCookieを無効化する。秘密鍵を変更すると全参加者が再認証になる。

## 無料ホスティング候補

個人・非商用の発表会利用に限定できる場合、Next.jsをそのままデプロイでき、環境変数とMiddlewareを利用できるVercel Hobbyを候補とする。無料枠・利用規約・公開範囲はデプロイ直前に確認する。会社業務・営利利用に該当する場合はHobbyを前提にせず、会社の承認済み環境または適切な有償プランを選ぶ。

Cloudflare Pages/Workersは無料枠候補だが、現在の `ai/published/` のローカルファイル読取はWorkerでは使えない。採用する場合は、公開済みJSONをR2/D1等へ置くRepository Adapterへ置換してから行う。

## 発表会チェックリスト

1. パスワードと32文字以上の秘密鍵を設定する。
2. シークレットをリポジトリ・画面・スクリーンショットに含めない。
3. シークレット未設定時は認証不能となり、サイト本文・APIは保護されたままであることを確認する。
4. 指定レースだけを権利確認済みCSVから取り込む。未承認モデルや合成データは公開しない。
5. URLとパスワードを許可された関係者だけに共有し、終了後にローテーションする。
