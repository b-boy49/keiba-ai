# 東京ダート2100m研究モデル：評価・比較記録

更新日: 2026-10-23  
用途: 内部研究・発表会準備のみ。一般公開用の予想、公開 API、JSON スナップショットには使用しない。

## 対象と分割

権利台帳で研究用途に限定されたローカル隔離データから、東京・ダート2100mの確定結果を特徴量化した。対象は743レース、10,450出走馬で、1990-01-27から2025-02-16までである。元データの取得可能期間は2025-03-27までだが、対象条件に該当する最終レースは2025-02-16だった。

| 区分 | レース日 | 出走馬数 | レース数 | 用途 |
| --- | --- | ---: | ---: | --- |
| 学習 | 1990-01-27〜2015-06-06 | 5,951 | 431 | モデル学習 |
| 検証 | 2015-06-07〜2019-06-23 | 2,224 | 154 | 確率校正 |
| テスト | 2019-10-14〜2025-02-16 | 2,275 | 158 | 未使用の最終評価 |

レース日で時系列分割し、同日の全レースが終わるまで結果を履歴へ反映しない。`finish_position`、走破時計、最終オッズ等の結果確定後情報は特徴量に含めない。

## 特徴量と評価方法

特徴量は距離、芝・ダート、馬の直近着順平均、距離経験、騎手勝率、前走からの日数、ダート2100mでの着順平均、東京での出走数・着順平均、騎手と馬の組合せ実績、馬場状態である。勝者を1としたレース内の相対的な `reference_win_score` を出力し、次をテスト158レースで測定した。

- Top1: 予測1位が勝馬である率
- Top3: 予測上位3頭に勝馬を含む率
- Brier / log loss: 参考スコアの順位品質・校正の確認指標。公開用の勝率ではない。

## ベースライン比較

| 方法 | Top1 | Top3 | Brier | Log loss |
| --- | ---: | ---: | ---: | ---: |
| LightGBM研究モデル | 19.62% | 44.30% | 0.0631 | 0.2417 |
| 単純ベースライン（直近着順平均のみ） | 15.19% | 45.57% | 0.0628 | 0.2412 |
| ランダム一様選択（200試行の平均±標準偏差） | 7.19% ± 1.96pt | 21.25% ± 3.10pt | 0.0662 | 0.2734 |

研究モデルはランダム予想と比べてTop1・Top3とも良く、単純ベースラインに対してTop1は4.43ポイント高い。一方で、Top3、Brier、log lossは単純ベースラインを上回っていない。このため、現時点では精度改善の根拠が十分ではなく、承認・公開の候補にはしない。

## 内部照合レポート

次のコマンドは、各テストレースについて予測上位3頭、実際の勝馬、過去成績由来の判断根拠項目を、隔離ディレクトリにだけ出力する。入力の権利証跡が検証できない場合は中止する。

```powershell
python -m ai.cli research-evaluation --input ai/quarantine/kblueleaf_tokyo_dirt_2100_authorized.csv --model ai/quarantine/artifacts/candidate-20261023T110205Z --output ai/quarantine/reports/tokyo_dirt_2100_benchmark.json
```

このレポートは実在馬名と結果を含みうるため、リポジトリ、`public/`、Next.js API、公開用スナップショットへ配置しない。

## 2026年11月7日に向けた準備

対象レースの確定出走馬・枠順・騎手・斤量、および2025年3月以降の確定結果が不足している。権利と用途を確認できた提供元から、既存のCSV取込・権利台帳を通じてのみ追加する。未確認の出走馬情報は登録も予測も行わない。

JRAは通常、木曜日16時頃に出馬投票の結果を公表し、前日10時頃に枠順を含む出馬表を確定する案内をしている。直前に正規の利用許可を確認し、権利確認済みCSVを手動登録する手順を準備する。自動取得機能は追加しない。

無料で再利用可能な最新JRA結果の公式提供元は確認できていない。JRA-VAN Data Lab.は有料サービスであり、公開Webサイトでのデータ利用についても制約が示されているため、本件の無料・限定公開方針の取得元には採用していない。法的評価は確定的な結論ではなく、個別の利用規約・契約と専門家確認を要する。
