# Phase 3 データ取得元の比較調査

調査日: 2026-10-23（JST）  
対象: JRA中央競馬の開催日程、特別登録、出馬表・枠順、過去成績、オッズ、結果・払戻金。

## 結論

**無料・一般公開サイトへの掲載／再配布可・安定した機械連携可を同時に満たすデータ提供元は、今回の調査では確認できなかった。** よって、Phase 3では自動取得を実装しない。公開用の実データ連携は、権利者との契約または書面での再配布許諾を得た後に限る。

JRA公式サイトは開催日程、特別登録馬、出馬表、オッズ、レース結果、払戻金、騎手・競走馬情報を閲覧用に提供している。一方、公開REST API、プログラムによる取得、保存、再配布を許すライセンスは今回確認できなかった。閲覧可能であることを自動取得・再掲載の許可と解釈しない。

| JRA公式Webサイト | 公式の閲覧用サイト | 開催、特別登録、出馬表、オッズ、結果・払戻金を画面で確認可能 | 無料 | **未確認。許諾なしでは不可として扱う** | 公式情報として更新されるが、機械利用のSLA・レート上限・API仕様は未公表 | 画面確認のみ。自動取得しない |

## 提供元ごとの確認事項

### 1. JRA公式Webサイト

- [JRAトップ](https://www.jra.go.jp/) は、出馬表、オッズ、レース結果、開催日程、払戻金、騎手・調教師データ、特別レース登録馬、競走馬検索への導線を公開している。
- [JRA「ご利用に際して」](https://www.jra.go.jp/use/) は、JRAのインターネット媒体に掲載された映像・音声・画像・記事等がJRAまたは第三者の著作物であり、二次利用には事前許諾が必要である旨を示す。本文は主に著作物一般・映像等を対象にするため、個々の競走データを機械取得・再配布できるという許可にはならない。
- **APIの扱い**: 調査したJRA公式ページでは、一般公開向けの競走データREST API、レート制限、再配布ライセンスを確認できなかった。これは「APIが存在しない」の断定ではなく、「本プロジェクトで利用許可を確認できる公開APIを発見できなかった」という調査結果である。
- **結論**: HTML解析、非公開エンドポイントの利用、画面からの定期取得、保存済み情報の公開は実装しない。利用したい項目と公開形態を列挙し、JRAへ書面で照会する。

### 2. JRA-VAN Data Lab. / JV-Link

- [Data Lab.製品ページ](https://jra-van.jp/dlb/) は、毎日更新・1986年から約40年分のJRA公式競馬データを案内する。開催・出馬表・過去成績・騎手・オッズ・結果の学習／分析データ源としては充足度が高い。
- 調査日時点の案内価格は月額2,090円（税込）であり、無料条件を満たさない。
- [JRA-VAN利用規約](https://app.jra-van.jp/rule/rule.html) はJV-Link以外からData Lab.サーバへアクセスする行為や、アプリ取得データの他プログラム利用を禁じている。SDKの仕様外アクセスを設計しない。
- [JRA-VANスタッフの公式案内](https://developer.jra-van.jp/t/topic/899) は、JV-Linkデータを使ってエンドユーザーへデータを提供するアプリや商用利用は通常のData Lab.契約ではできず、JRADBが必要だと説明する。
- **結論**: 個人端末または社内環境で、利用規約に沿う分析ソフトとして使う可能性はある。ただしKEIBA AIのような公開Webサービスのサーバーに集約して配信する用途には採用しない。

### 3. JRADB

- 上記のJRA-VAN公式スタッフ案内では、エンドユーザー向けデータ提供を伴う商用利用にはJRAの商業利用契約「JRADB」が必要とされている。
- 料金、契約対象データ、キャッシュ、表示項目、AI学習、第三者提供、広告付き無料公開の扱い、更新頻度、API／配信方式は公開情報だけでは確認不足である。
- **次の確認質問**: (1) 無料公開サイトの可否、(2) レース・出走馬・結果・払戻・オッズ・過去成績それぞれの表示可否、(3) AI学習と特徴量保存の可否、(4) 再配布／キャッシュ期間、(5) 開発・検証環境の費用、(6) SLA・上限・障害通知、(7) 出典表示・商標要件。

### 4. OSS・非公式スクレイパー

- OSSは取得ロジックの参考にはなっても、データ提供元のライセンスや再配布権を付与しない。
- 非公式の「API」と称するものは、公開された正規APIではなく、HTMLスクレイピングや非公開通信に依存する場合がある。提供元の明示許諾、利用規約、レート制限、データの再配布権が確認できない限り、利用可能とは判定しない。
- **結論**: 本プロジェクトには組み込まない。採用検討時には、特定リポジトリのライセンス、実際のアクセス先、アクセス先規約、公開形態を別途審査する。

## データ項目別の方針

| 項目 | 公開用の現在方針 | AI学習の現在方針 |
|---|---|---|
| 開催カレンダー | 許諾済みデータまたは明示的なデモのみ | 同左 |
| 特別登録馬 | 登録馬と確定馬を区別。許諾前は表示しない | 許諾済みの場合のみスナップショット保存 |
| 出馬表・枠順 | `ENTRIES_PUBLISHED` / `DRAW_CONFIRMED` に対応。未取得時は待機表示 | 予測時点で公開済みのものだけ利用 |
| 過去成績・馬・騎手 | 公開Webへの再配布は許諾確認後 | Data Lab.等を使う場合も利用範囲を個別確認 |
| オッズ | 許諾と時点管理が確認できるまで表示しない | `observed_at` 付きスナップショットだけを利用 |
| 結果・払戻金 | 結果確定と公開権を確認後に表示 | 予測と分離して保存し、事後改変しない |

## 採用提案とリスク

1. **当面**: `DemoRaceRepository` を維持し、画面ではデモ／未取得を明示する。
2. **公開サービスの採用候補**: JRADBまたは同等の、書面で公開・再配布・AI利用を許諾する提供元。契約締結前は接続しない。
3. **開発・分析候補**: Data Lab.は規約と費用を受け入れ、データを公開サーバーへ転送しない前提でのみ検討する。
4. **主要リスク**: 権利侵害、規約違反、仕様変更、オッズの鮮度、登録馬と確定馬の混同、学習時の未来情報リーク、契約外のキャッシュ・再配布。

## Phase 6A追補: Wikidata（調査日 2026-10-23）

- Wikidataの構造化データはCC0として公開されており、再利用・配布・商用利用を含む利用の候補になり得る。補助的な馬名、血統、Wikidata識別子などの**馬メタデータ**に限定して検討する。
- Wikidataは共同編集の二次知識ベースであり、JRAの公式開催カレンダー、特別登録馬、確定出馬表、枠順、オッズ、結果、払戻金の完全性・速報性・網羅性を保証するものではない。これらをWikidataで代替できるとは扱わない。
- 将来APIを利用する場合は、識別可能なUser-Agent、低頻度アクセス、応答のレート制限・バックオフ指示への従属、キャッシュと障害時停止を実装する。Phase 6Aでは外部アクセス処理は追加しない。
- `ai/rights/providers.json` では `wikidata-cc0` の許可範囲を `horses` のみへ限定した。レース・出走馬・結果等をこの提供元として取り込もうとすると失敗する。

## v0.9 追補: 無料実データ導入準備（調査日 2026-10-23）

- Wikidata Action API は小規模な明示Q-id取得だけに採用候補とする。CC0はWikidataの構造化データの再利用条件であり、外部識別子の先のデータ利用権を意味しない。
- `ai.cli import-wikidata-horses` は、識別可能なUser-Agent、ローカルキャッシュ、1秒の最小間隔、`maxlag=5`、429/5xxの上限付きバックオフを実装した。Next.js/APIからは呼び出さない。
- Kaggle `takamotoki/jra-horse-racing-dataset`、その利用を記すGitHubプロジェクト、第三者サイトをスクレイピングするGitHubプロジェクトは、元データの用途別権利証跡を本リポジトリで確認できない。このため提供元台帳に追加せず、取込・学習・公開には使用しない。
- 詳細な項目対応、未取得項目、2026-11-07 東京9Rの不足データは `docs/wikidata-horse-integration.md` に記録する。

## v0.9 追補: 実データ学習候補の再評価（調査日 2026-10-23）

- Hugging Face `KBlueLeaf/jp-racing-horse` はApache-2.0表示だが、READMEはライセンス行だけで、`db.py` の `time_factor from Netkeiba` という記述を含め、原データの取得・再許諾の根拠を確認できない。したがって提供元台帳へ追加せず、1.04GB DBもダウンロードしない。
- JRAの過去結果は公開閲覧・PDF掲載を確認したが、AI学習および複製/再配布を許す無料の公式データライセンス/APIは確認できない。
- 地方競馬情報サイトには無料CSV機能があるが、利用規約が掲載情報の無断転載・複製を禁止する。AI学習用の保存・変換は実施しない。
- JRDB APIはAPIキーと認証キーが必要であり、無料運用・公開利用権は確認できない。
- 結果として、今回取得できた権利確認済みの日本競馬「過去レース結果」は0件。実データ学習、Top1/Top3評価、神奈川新聞杯の実予想は未実施である。根拠とCSV対応案は `docs/huggingface-jp-racing-horse-assessment.md` に記録する。
- Kaggle・GitHubのデータセットは、掲載場所のライセンスではなく元データの取得・保存・学習・公開・再配布権限まで確認できるまでは台帳へ登録しない。
